# Speedshop

Ruby on Rails performance consultancy website. Jekyll static site hosted on S3 with Cloudflare CDN.

## Stack

- **Site**: Jekyll 4.3.3, Markdown source content
- **Hosting**: S3 static hosting + Cloudflare CDN
- **Markdown**: Cloudflare Markdown for Agents, with native URL/header transforms for explicit `.md` URLs
- **Workers**: Dedicated `/card` endpoint
- **CI/CD**: GitHub Actions → S3 deploy → Cloudflare cache purge
- **Infrastructure**: Canonical Terraform lives in the sibling `../infra` repository; remote plans/applies run in HCP Terraform

## Testing

Run tests with mise:

```bash
mise run test                   # Ruby, browser, links, local HTTP, system tests
mise run test:ci                # CI suite
mise run lint                   # StandardRB
mise run test:ruby
mise run test:browser
mise run test:links
mise run test:integration       # Isolated static site; skips Cloudflare-only behavior
mise run test:integration:prod  # Production Markdown, card, redirects and document downloads
```

Test builds use isolated temporary destinations, not the development watcher's `_site`.

## Local Development

`mise run dev` builds/watches Jekyll and serves the static site with Caddy at
`https://localhost:4000`. Managed Markdown conversion and `.md` aliases are
production Cloudflare features, not local static files. The dedicated card worker
can be developed with `npx wrangler dev --config workers/card-wrangler.toml`.

## Markdown and Document Downloads

Production pages return HTML normally and Markdown with `Accept: text/markdown`.
Explicit `.md` URLs return Markdown without a special header, including
`/index.md`, `/retainer.md`, `/retainer.html.md`, `/blog/post.md`,
`/blog/post/index.md`, and `/blog/post/.md`. These are native Cloudflare rewrites
and request-header transforms; the build does not generate page Markdown files.

`/llms.txt` lists canonical pages and explains Markdown access. Cloudflare supplies
the default `Content-Signal` policy, including `ai-train=yes`.

PDF and EPUB downloads remain generated by Pandoc/XeLaTeX, including blog slug
aliases. Do not remove their build dependencies when changing Markdown behavior.
